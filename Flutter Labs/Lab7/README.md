# Lab 7 — Notes App

## Опис
Це Flutter-проєкт `notes_app`, який реалізує простий додаток для зберігання нотаток.
У ньому використовується локальна база даних SQLite через пакет `sqflite`, а також мережевий запит для завантаження прикладів нотаток.

## Основні можливості
- Створення нотатки з назвою та описом
- Збереження даних у локальній базі SQLite
- Оновлення списку нотаток
- Видалення нотаток свайпом
- Завантаження прикладів нотаток з інтернету

## Технічні деталі
- Основний файл: `notes_app/lib/main.dart`
- База даних: `sqflite` + `path`
- HTTP-запити: `http`
- Інтерфейс: Material 3, `Scaffold`, `AppBar`, `AlertDialog`, `SnackBar`

## Запуск
1. Відкрий термінал у папці `Flutter Labs/Lab7/notes_app`
2. Виконай команду:
   ```bash
   flutter pub get
   ```
3. Запусти додаток:
   ```bash
   flutter run
   ```

## Примітки
- Для коректної роботи додатка потрібне середовище Flutter та емулятор або реальний пристрій.
- Додаток зберігає нотатки локально, тому дані зберігаються між запусками.
